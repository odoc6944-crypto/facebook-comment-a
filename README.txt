FACEBOOK COMMENT-TO-DM WEBSITE STARTER

This ZIP contains the starter files for your website.

PLEASE NOTE:
This is a starter project, not a finished Facebook automation service.
It provides a website page and a webhook endpoint. It does NOT yet send
messages to commenters. That requires a Meta developer app, a Facebook Page,
the correct permissions, a public HTTPS hosting address, and a compliant
Messenger API implementation. Meta may require app review.

WHAT IS INSIDE:
- public/index.html : the simple website page
- server.js         : the web server and webhook endpoint
- package.json      : the server dependencies
- .env.example      : example settings (do not share secret tokens)
- .gitignore        : keeps private settings out of GitHub
